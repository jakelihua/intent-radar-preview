      IntentRadar · 四步商机资格核验与证据规范

      严格区分「抱怨竞品 → 正在评估替代 → 产品能力匹配 → 可触达推进」

      1. 原帖证据可追溯性

      每条样本绑定官方 API source_id、发布时间、采集时间与支持关键判断的原文摘录，点击即可核对原帖。

      2. 三态资格标注与负向样本拦截

      团队规模、预算、决策权、迁移期限分别标记【原文明示 / 模型推断 / 未知】。明示无选型权（如 hn_37146814）自动拦截推销。

      3. 卖方能力门控与跨赛道拦截

      配置特定卖方产品后，系统先校验被替换竞品是否属于目标赛道；跨赛道线索禁止强行套用推荐话术。

      4. 透明利益披露与安全导出

      所有社区回复强制披露开发者身份并列出待确认边界；支持导出真实 OpenXML .xlsx 与防公式注入 CSV。
